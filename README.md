# ระบบคำนวณและจัดการภาษีเงินได้บุคคลธรรมดา

โปรแกรมคอนโซล (Console Application) เขียนด้วยภาษา Python สำหรับคำนวณภาษีเงินได้บุคคลธรรมดาแบบขั้นบันได พร้อมบันทึกข้อมูลผู้เสียภาษี จัดการค่าลดหย่อน

จัดทำเป็นโปรเจกต์รายวิชาพื้นฐานการเขียนโปรแกรมภาษา Python

---

## ฟีเจอร์หลัก

- คำนวณภาษีเงินได้ตามอัตราขั้นบันได
- จัดการค่าลดหย่อนหลายประเภท (ส่วนตัว, คู่สมรส, บุตร, ประกัน, กองทุน ฯลฯ)
- บันทึก / แก้ไข / ลบ ข้อมูลผู้เสียภาษี พร้อมเก็บลงไฟล์ถาวร
- ตรวจสอบความถูกต้องของเลขบัตรประชาชน 13 หลัก
- แสดงผลสรุปภาษีเป็นตาราง พร้อมกราฟสัดส่วนแบบ ASCII ("█")
- ส่งออกใบสรุปภาษีเป็นไฟล์ข้อความ
- เกมควิซทดสอบความรู้เรื่องภาษี

## ความต้องการของระบบ

- Python 3.10 ขึ้นไป
- ไม่ต้องติดตั้งไลบรารีภายนอกเพิ่มเติม (ใช้เฉพาะ standard library)

## วิธีติดตั้งและเริ่มใช้งาน

```bash
git clone <https://github.com/123456789i0/tax_system.git>
cd tax_system
python main.py
```

เมื่อรันแล้วจะพบเมนูหลักในคอนโซล ให้เลือกตัวเลขตามรายการที่ต้องการ

## โครงสร้างโปรเจกต์

```
tax_system/
├── main.py              # จุดเริ่มโปรแกรม และเมนูหลัก
├── config.py            # ค่าคงที่: อัตราภาษี, กฎค่าลดหย่อน
├── core/                # ตรรกะการคำนวณ (ไม่มีการรับ-แสดงผล)
│   ├── calculator.py
│   ├── deduction.py
│   └── validator.py
├── io_utils/            # การจัดการไฟล์และการแสดงผล
│   ├── storage.py
│   └── display.py
├── extras/               # ฟีเจอร์เสริม: เกม, โหมดเปรียบเทียบ
│   ├── quiz.py
├── data/                 # ข้อมูลที่บันทึกไว้ (.txt)

```

## ตัวอย่างการใช้งาน

```
==== ระบบจัดการภาษีเงินได้บุคคลธรรมดา ====
1. เพิ่มข้อมูลผู้เสียภาษี
2. คำนวณภาษี
3. ดูข้อมูลที่บันทึกไว้
4. แก้ไข / ลบข้อมูล
6. เล่นเกมควิซภาษี
0. ออกจากโปรแกรม
เลือกเมนู: _
```

## ข้อจำกัดของโปรแกรม

โปรแกรมนี้จัดทำเพื่อการศึกษา อัตราภาษีและเพดานค่าลดหย่อนที่ใช้เป็นข้อมูลอ้างอิง ณ ช่วงเวลาที่พัฒนา **ไม่ควรใช้แทนการคำนวณภาษีจริงหรือคำปรึกษาทางภาษี** ควรตรวจสอบอัตราและเงื่อนไขล่าสุดจากกรมสรรพากรเสมอ

## ผู้จัดทำ

โปรเจกต์กลุ่ม 4 คน รายวิชาพื้นฐานการเขียนโปรแกรมภาษา Python

| บทบาท | ผู้รับผิดชอบ |
|---|---|
| Core (สูตรคำนวณ) | สมาชิก A |
| Data (ไฟล์และการตรวจสอบ) | สมาชิก B |
| UI (เมนูและการแสดงผล) | สมาชิก C |
| Extras + QA (ฟีเจอร์เสริมและทดสอบ) | สมาชิก D |
